# akiovaska.github.io

Aki Ovaska's static identity hub. It has four useful links and considerably more atmospheric CSS than four links strictly require.

Live site: [akiovaska.github.io](https://akiovaska.github.io/)

## Quick start

Open [`index.html`](index.html) in a browser. There is no build step to summon.

## Deployment

The [GitHub Pages workflow](.github/workflows/deploy-pages.yml) publishes only the website files from `main`.
